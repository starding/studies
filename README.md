## How this collection is organised　组织方式

- **One study, one directory.** The directory name is an English slug and is also the URL path.
  一个专题一个目录，目录名是英文短横线命名，同时也是网址路径。
- **Self-contained.** `index.html` is the Chinese edition, `en/index.html` the English one; images and other assets live in the same directory. There is no shared build step, so adding or changing one study never touches another.
  目录内自包含：`index.html` 是中文版，`en/index.html` 是英文版，图片等资源放在同一目录。没有共享的构建步骤，增改一个专题不影响其他专题。
- **What belongs here.** Studies that fit in a single page or deck.
  收录能用一页或一组幻灯讲完的专题。
- **What does not.** Multi-chapter web books with their own build pipeline, and software or tools with their own releases, keep their own repositories.
  有独立构建流程的多章节网页书，以及有自己发布节奏的软件与工具，继续使用各自的仓库。
- **Adding a study.** Create the directory, then add one row to the table above and one entry to the root `index.html`.
  新增专题：建目录，然后在上表和根目录 `index.html` 各加一行。
